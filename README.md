# Telco-Customer-Churn-Analysis
A brief case study of the Telco Company dataset. In this case study i have analyzed 7k+ records to complete the analysis of customer churn. I have used Python for data cleaning and building a machine learning model, SQL for data calculations and Excel and tableau for data visualization.
